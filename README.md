## Editing

Everything is in `index.html`. To add a project, add an object to the `projects` array in the script at the bottom of the file. There's no build step.

## Deploy

It's hosted on GitHub Pages from the root of the `master` branch (Settings → Pages → Deploy from a branch → `master` / `(root)`).
